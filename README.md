# 灵感之锤 Inspiration Hammer

> 一把灵感之锤，锤开你的脑思维。

灵感之锤是一个给 AI Agent 使用的创意思维扰动 Skill。

它不替用户生成完整创意，而是先提供三个意外的「灵感洞」；用户选择其中一个后，再给出三个短而具体的问题。AI 负责制造意外，意义仍由人来创造。

## 为什么做它

在 AI 越来越擅长替人完成工作的时代，我想反过来用 AI 保护人的创造过程。

很多创意工具都在缩短从需求到答案的距离。灵感之锤想做的是另一件事：把这段距离稍微拉长，让发散、走神、碰撞和那些还不成熟的念头有机会发生。

它保护的不是某个答案，而是人的想象力。

## 它怎么工作

1. 用户写下一个初版需求。
2. 选择「自由锤击」或补充背景后「智能锤击」。
3. Skill 根据开放度生成三个不同来源的灵感洞。
4. 用户可以重新锤，或者选择一个洞「看看洞里边」。
5. Skill 只给三个短问题，然后停下。

示例：

```text
如果你的猫才是客户呢？

如果这件事必须倒着做呢？

如果公司才是来求职的那一方呢？
```

## 核心边界

- 不生成完整创意方案。
- 不自动补齐脚本、文案、传播链路或执行细节。
- 不评价哪个洞最好。
- 不把「深入」变成替用户完成答案。
- 问题之后保留停顿。

## 安装

### Codex

将 `skill/inspiration-hammer` 文件夹复制到个人 Skills 目录：

```text
~/.codex/skills/inspiration-hammer
```

重新打开 Codex 后，可以直接说：

```text
使用 $inspiration-hammer，我想为一个汽车品牌做一条出圈的测试片。
```

也可以使用自然语言触发：

```text
帮我开个脑洞。
给我三个灵感洞。
灵感之锤，开锤。
```

### 其他支持 Agent Skills 的工具

复制 `skill/inspiration-hammer` 整个文件夹到对应工具的 Skills 目录。不要只复制 `SKILL.md`，生成引擎还依赖：

```text
references/engine.md
```

## 目录

```text
skill/inspiration-hammer/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── engine.md
```

## 适合什么场景

- 广告与品牌创意
- 内容、短片与活动概念
- 产品与服务构想
- 个人项目
- 已经被一个熟悉方向困住的 Brief
- 只有模糊念头、想先发散一下的时刻

## 生成标准

> 看得懂，想不到；问得短，想得远。

随机不是拼词。一个好的灵感洞需要从陌生领域搬来真实的动作、规则、关系、系统或因果，而不只是换一个场景或视觉风格。

## 语言

Skill 默认使用中文交互。核心机制可以根据使用环境适配其他语言，但应始终保持短、具体、有画面，并避免 AI 腔。
